### Final Year Project – Heart Disease Prediction Using Machine Learning and Fuzzy Logic

This project was developed as part of my undergraduate studies in Bachelor of Computer Science (Software Engineering) at Universiti Malaysia Pahang Al-Sultan Abdullah (UMPSA).

The primary objective of this project was to investigate and improve the accuracy of heart disease prediction by integrating three different feature selection techniques with Fuzzy Logic. The project evaluated and compared the performance of the following three approaches:

1. **Recursive Feature Elimination (RFE) + Fuzzy Logic**
2. **LASSO Regression + Fuzzy Logic**
3. **Mutual Information + Fuzzy Logic**

Each approach was implemented and evaluated using training and testing datasets to determine which combination achieved the highest predictive accuracy and overall classification performance on unseen testing data.

Based on the evaluation results, the best-performing approach was selected and integrated into a web-based application developed using the **Flask framework (Python)**. The application was designed to assist medical practitioners in conducting preliminary heart disease risk assessments by analysing patient-related input data and providing an initial prediction of the likelihood of heart disease.

The application was deployed using **GitHub for source code management and Vercel for hosting**, making the prototype accessible through a web interface.

The project aimed to demonstrate how machine learning and fuzzy logic techniques could be combined to support preliminary clinical decision-making. However, the application was intended as a decision-support prototype rather than a replacement for professional medical diagnosis.
